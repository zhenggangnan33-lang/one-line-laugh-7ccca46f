## The line

> My smartwatch congratulated me for standing up, making it the only boss ever proud of me for doing the bare minimum.

## How it works

`main.ts` (Node 22, stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), creating the directory if needed, then reads it back and throws if it differs byte-for-byte.

```sh
node main.ts
```
